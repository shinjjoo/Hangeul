# 🐣 초등 1학년 쑥쑥 한글 배움터

> 아직 한글을 읽고 쓸 줄 모르는 초등학교 1학년 어린이들을 위한 맞춤형 첫 한글 공부 웹앱입니다.
> 훈민정음 제자 원리(찬찬한글)에 기반한 음운 인식 및 받침 없는 단어 중심의 단계별 학습을 지원합니다.

---

## 🌟 주요 학습 기능 (7대 배움터)

1. **📢 소리 듣기 (소리 탐험관)**: 기본 자음 14자, 기본 모음 10자의 표준 발음과 대표 낱말(🎒 가방, 🦋 나비 등) 소리 익히기
2. **🎴 낱말 카드 (118선)**: 초등 1학년 생활 어휘 중 받침이 없는 118개 단어를 3D 카드로 뒤집으며 자모음 분절(`ㄴ+ㅏ = 나`)과 함께 반복 학습 (에빙하우스 간격 반복)
3. **🪄 글자 합체 마법**: `자음` + `모음` = `완성 글자`가 되는 훈민정음 원리 시각 체험
4. **✏️ 따라 쓰기**: 획순 가이드와 균형 모눈 보조선 위에서 마우스나 손가락 터치로 글씨 바르게 쓰기
5. **❓ 낱말 퀴즈**: 커다란 그림 이모지를 보고 첫 글자를 맞추는 4지선다 놀이
6. **📝 수준별 평가**: 1수준(새싹: 소리), 2수준(꽃잎: 단어), 3수준(열매: 빈칸 완성) 3단계 성취도 진단
7. **🏆 칭찬 스티커판**: 배운 만큼 별이 모이고 칭찬 스티커가 열리는 자기주도적 보상 시스템

---

## 📄 학부모 가정 연계 통지표
- 학교와 가정이 함께 지도할 수 있도록 누적 평가 결과 및 취약 글자를 자동 분석합니다.
- 학생별 맞춤 조언문과 함께 **A4 인쇄(Print)** 레이아웃을 기본 지원합니다.

## 🚀 기술 스택
- **프론트엔드**: React 18, Vite 6, Tailwind CSS
- **사운드 & 그래픽**: Web Speech API (한국어 TTS), HTML5 Canvas, Canvas-Confetti, Lucide Icons
- **보안 & 데이터**: 학생 개인정보 암호화 및 로컬 스토리지 안전 저장 (무서버/독립 구동)
- **배포**: GitHub Actions 자동 배포 (GitHub Pages)
