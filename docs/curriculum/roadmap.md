# 📖 초등 1학년 쑥쑥 한글 지도 로드맵 & 교수학습 가이드

본 가이드는 초등학교 1학년 한글 미해득 학생들을 효과적으로 지도하기 위해 **2022 개정 국어과 교육과정** 및 **훈민정음 제자 원리(찬찬한글)**에 기반하여 설계된 표준 지도 단계입니다.

---

## 1. 한글 지도 기본 원칙

1. **소리 우선의 원칙 (발음 중심 지도법)**:
   - 글자를 눈으로 보기 전에 먼저 귀로 말소리를 듣고 구별하는 음운 인식 훈련을 선행합니다.
   - 예: '나비'를 배울 때 [느] + [아] ➔ [나], [브] + [이] ➔ [비] 소리의 결합을 귀로 먼저 경험하게 합니다.

2. **직관적 시각 단서 제공**:
   - 아직 글자를 모르는 아이들에게는 글자 자체보다 **사물 이모지(🎒, 🦋 등)**가 유일한 의미 연결고리입니다.
   - 모든 글자는 친숙한 생활 속 그림과 함께 1:1로 제시되어야 합니다.

3. **실패 없는 학습 (긍정적 강화)**:
   - 1학년 아이들은 작은 실패에도 쉽게 배움을 포기합니다.
   - 틀린 답을 골라도 "틀렸어!" 대신 **"아쉽다! 다시 한 번 들어볼까?"**처럼 다정하고 격려하는 음성 피드백을 제공합니다.

---

## 2. 5단계 한글 지도 체계

```
[1단계] 소리 탐색관: 기본 모음(10자)과 기본 자음(14자) 소리 익히기
   ▼
[2단계] 글자 합체 마법: 자음(첫소리) + 모음(가운뎃소리) 결합 원리 체험 (예: ㄱ + ㅏ = 가)
   ▼
[3단계] 따라 쓰기 놀이터: 획순 가이드와 균형 보조선 위에서 손가락 크레파스로 쓰기
   ▼
[4단계] 쑥쑥 낱말 퀴즈: 소리 듣고 글자 맞추기, 그림 보고 첫 글자 짝짓기 놀이
   ▼
[5단계] 칭찬 스티커북: 매일매일 글자를 배우고 도장을 모으는 자기주도 학습
```

## 3. 교사 및 음성 피드백 발문 스크립트

| 상황 | 음성 피드백 멘트 | 효과 연출 |
| :--- | :--- | :--- |
| **글자 선택 시** | "{글자이름}! {글자소리}! {단어}의 {글자}예요!" | 카드 젤리 바운스 + 소리 재생 |
| **합체 성공 시** | "{자음}과 {모음}이 만나서 짠! {완성글자}가 되었어요!" | 별빛 반짝임 + 팡파레 효과 |
| **따라쓰기 완료** | "와, 정말 멋지게 썼어요! 글씨 쓰기 왕 도장 쾅쾅!" | 칭찬 도장 애니메이션 + 무지개 폭죽 |
| **퀴즈 정답 시** | "정답이에요! 정말 똑똑하네요, 최고예요!" | 파티클 폭죽 + 별 획득 |
| **퀴즈 오답 시** | "괜찮아요! 한 번 더 천천히 소리를 들어볼까요?" | 부드러운 고개 갸웃 애니메이션 |
