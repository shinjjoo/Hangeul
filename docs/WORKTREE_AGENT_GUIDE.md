# 🌳 한글 배움터: Git 워크트리(Worktree) 및 에이전트 협업 가이드

이 문서는 초보 교육자 분들도 쉽게 이해할 수 있도록 **Git 워크트리(Worktree)**와 **AI 에이전트**를 연동하여 초등 1학년 한글 교육 앱을 안전하게 개발하는 방법을 안내합니다.

---

## 1. Git 워크트리(Worktree)란 무엇인가요?

일반적으로 Git에서는 다른 기능을 만들 때 브랜치를 바꾸면(`git checkout`) 폴더의 파일들이 순식간에 바뀌어서, 작업 중이던 내용이 엉키거나 충돌할 위험이 있습니다.

하지만 **워크트리(Worktree)**를 쓰면:
- 하나의 프로젝트 안에서 **여러 개의 독립된 작업 폴더(`.worktrees/...`)**를 동시에 열어둘 수 있습니다.
- 예를 들어 **A 에이전트**는 UI 디자인 화면을 고치고, **B 에이전트**는 소리와 퀴즈를 개발할 때 서로의 코드를 절대 건드리지 않고 안전하게 각자의 폴더에서 작업할 수 있습니다.

---

## 2. 현재 설정된 워크트리 및 에이전트 역할

| 워크트리 폴더 | 연결된 브랜치 | 담당 에이전트 역할 | 주요 작업 내용 |
| :--- | :--- | :--- | :--- |
| **`main` (기본 폴더)** | `main` | 메인 총괄 에이전트 | 전체 프로젝트 조율, 테스트 및 병합(Merge) |
| **`.worktrees/ui-design`** | `feat/ui-design` | **UI/UX 디자인 에이전트** | 1학년 눈높이 큰 글씨, 알록달록 색상, 테마, 반응형 화면 |
| **`.worktrees/audio-interactive`** | `feat/audio-interactive` | **오디오 & 인터랙션 에이전트** | 또박또박 한글 TTS 소리, 따라쓰기 캔버스 손글씨 판정 |
| **`.worktrees/hangeul-quiz`** | `feat/hangeul-quiz` | **한글 교육 & 퀴즈 에이전트** | 1학년 맞춤형 글자 찾기 퀴즈, 동물 소리-글자 매칭 게임 |

---

## 3. 에이전트에게 작업을 지시하는 방법 (예시)

에이전트에게 다음과 같이 요청하시면 각 워크트리에서 독립적으로 작업이 진행됩니다:

1. **디자인 개선 요청 시**:
   > "UI 디자인 에이전트야, `.worktrees/ui-design` 폴더에서 따라쓰기 화면의 색상을 크레파스 느낌으로 더 귀엽게 바꿔줘."

2. **새로운 퀴즈 기능 추가 시**:
   > "퀴즈 에이전트야, `.worktrees/hangeul-quiz` 폴더에서 초등 1학년용 '그림 보고 첫 글자 맞추기' 퀴즈 컴포넌트를 만들어줘."

---

## 4. 작업한 결과물을 메인으로 합치기 (Merge)

각 워크트리에서 작업과 테스트가 끝나면 메인 저장소에서 아래 명령어로 깔끔하게 합칠 수 있습니다:

```bash
# 1. 메인 폴더로 이동 (기본 위치)
cd /Users/shinjoohan/antigravity/Hangeul

# 2. 퀴즈 기능이 완성되었다면 메인 브랜치로 가져오기
git merge feat/hangeul-quiz

# 3. 브라우저에서 잘 돌아가는지 확인
npm run dev
```

---

## 5. 자주 쓰는 유용한 명령어

- **워크트리 목록 확인**: `git worktree list`
- **워크트리 자동 점검/생성**: `./scripts/setup-worktrees.sh`
- **로컬 개발 서버 실행**: `npm run dev` (인터넷 창에서 즉시 앱을 체험할 수 있습니다)
